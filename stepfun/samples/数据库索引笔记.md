# 数据库索引笔记

## B+ 树索引
InnoDB 的主键索引是聚簇索引，叶子节点直接存放整行数据。二级索引的叶子节点存的是主键值，因此通过二级索引查非索引列时需要回表。

## 覆盖索引
如果一个查询需要的所有列都在二级索引里，就不需要回表，这种索引叫覆盖索引。EXPLAIN 的 Extra 列会显示 Using index。

## 最左前缀
联合索引 (a, b, c) 可以支持 a、a+b、a+b+c 的查询，但跳过 a 直接用 b 用不上索引。范围查询会让后面的列失去索引能力。

## 索引失效
在索引列上做函数运算、隐式类型转换、前导模糊匹配（LIKE '%x'）都会导致索引失效。
