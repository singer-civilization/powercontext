# 机器学习复习提纲

## 偏差与方差
偏差衡量模型对训练数据的拟合能力，方差衡量模型对数据扰动的敏感程度。欠拟合时偏差大，过拟合时方差大。

## 正则化
L1 正则倾向于产生稀疏解，可以做特征选择；L2 正则让权重整体变小，缓解过拟合。Dropout 可以看作一种集成方法。

## 注意力机制
自注意力用 Query 和 Key 的点积计算相关性，再用 softmax 归一化得到权重，对 Value 加权求和。多头注意力让模型同时关注不同位置、不同表示子空间的信息。

## 评估指标
分类任务常用准确率、精确率、召回率和 F1。样本不均衡时准确率会失真，此时更应看 PR 曲线和 AUC。
