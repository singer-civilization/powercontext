# 机器学习复习提纲

## 监督学习基本框架

- 目标：从训练集学习映射 f: X → Y，最小化泛化误差。
- 偏差-方差分解：泛化误差 = 偏差² + 方差 + 噪声。
- 模型太简单 → 欠拟合（高偏差）；模型太复杂 → 过拟合（高方差）。

## 过拟合怎么办

1. L2 正则化（权重衰减）：损失加 λ‖w‖²，压制大权重。
2. Dropout：训练时随机丢弃神经元，相当于集成。
3. 早停（early stopping）：验证集 loss 回升就停。
4. 数据增强、交叉验证选超参。

## 梯度下降家族

- SGD：每次一个样本，噪声大但能跳出浅局部极小。
- Mini-batch：折中，GPU 友好。
- Adam：动量 + 自适应学习率，默认首选优化器。

## 评估指标

- 分类：准确率、精确率、召回率、F1、AUC-ROC。
- 类别极不平衡时别看准确率，看 PR 曲线和 F1。
- 回归：MSE、MAE、R²。
